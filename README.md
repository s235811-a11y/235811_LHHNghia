# Hệ thống quản lý thiết bị phòng học

## Mô tả đề tài
Ứng dụng web quản lý thiết bị phòng học: thêm, xem, tìm kiếm, cập nhật, xóa thiết bị và theo dõi tình trạng sử dụng.

## Công nghệ sử dụng
React (Vite), Node.js, Express, MongoDB Atlas, Docker, Docker Hub, Render, GitHub.

## Cấu trúc dự án
- backend/: Express API
- frontend/: React app
